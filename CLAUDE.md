# ZYRA Project Guidelines

## Project Structure
- `frontend/`: Next.js 16 (React 19, Tailwind CSS v4, GSAP, Lenis, Three.js)
- `backend/`: Node.js, Express 5, MongoDB (Mongoose), Stripe, Razorpay

## Quick Commands
- Frontend Dev: `cd frontend && npm run dev`
- Backend Dev: `cd backend && npm run dev`
