# ZYRA
# 🛍️ Zyra Editions — Premium Brand Shopping Experience

**Zyra Editions** is a minimalist, high-end e-commerce platform built for a singular, premium brand. It combines editorial storytelling with a seamless shopping journey, focusing on product craftsmanship and an immersive user interface.

🔗 **Live Store:** [https://zyra-editions.vercel.app/](https://zyra-editions.vercel.app/)

---

## 💎 The Brand Experience

Unlike generic marketplaces, **Zyra** is designed to feel like a digital flagship store. Every transition and interaction is crafted to reflect the brand's premium identity, using motion to guide the user from discovery to purchase.

---

## ✨ Key Features

- **Product Storytelling:** High-resolution imagery and GSAP-powered parallax effects to showcase product details.
- **Editorial Product Grid:** A non-traditional, sophisticated layout for browsing collections.
- **Immersive Micro-interactions:** Fluid hover effects on product cards and smooth transitions between pages.
- **Performance Optimized Checkout:** Built with Next.js for lightning-fast page loads and a frictionless user flow.
- **Responsive Luxury:** A mobile-first shopping experience that maintains its premium feel on all devices.

---

## 🛠️ Technical Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (Custom Theme)
- **Motion & Smooth Scroll:** GSAP, ScrollTrigger, Lenis
- **Animations:** Framer Motion
- **Deployment:** Vercel
